🌎 TravelGram

Projeto de interface web inspirado em uma rede social de viagens, desenvolvido para praticar conceitos de desenvolvimento Front-end e construção de interfaces.

O TravelGram apresenta um perfil de viajante e uma galeria de registros de diferentes viagens.

🌐 Demonstração

O TravelGram possui uma versão publicada através do GitHub Pages.

👉 [Acessar demonstração do TravelGram](https://lfmenesesdev.github.io/Projeto-TravelGram/)

🚀 Funcionalidades

- Exibição de perfil do usuário
- Galeria de fotos de viagens
- Informações sobre o viajante
- Organização visual inspirada em redes sociais
- Interface para visualização dos registros de viagem

🛠️ Tecnologias

- HTML5
- CSS3
- Git
- GitHub

📁 Estrutura do projeto

Projeto-TravelGram/
├── assets/
├── styles/
├── index.html
└── .gitignore

🎯 Objetivo do projeto

O TravelGram foi desenvolvido com o objetivo de praticar conceitos fundamentais de desenvolvimento Front-end, como:

- Estruturação de páginas com HTML
- Estilização com CSS
- Organização de componentes visuais
- Construção de layouts
- Organização de arquivos e assets
- Versionamento com Git e GitHub

▶️ Como executar

Clone o repositório:

git clone https://github.com/LFMenesesDev/Projeto-TravelGram.git

Entre na pasta:

cd Projeto-TravelGram

Depois, abra o arquivo "index.html" em seu navegador.
